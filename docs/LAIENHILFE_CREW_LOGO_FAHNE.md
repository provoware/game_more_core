# Laienhilfe – eigenes Crew-Logo oder eigene Fahne

## Was kann ich einstellen?

Im Profil erscheint ein neuer Bereich **Logo oder Fahne**. Dort wählst du:

- Logo oder Fahne,
- einen Flächenstil,
- ein Symbol,
- Primär-, Sekundär- und Akzentfarbe,
- optional eine Kurzmarke mit höchstens vier Zeichen.

Die Vorschau reagiert direkt auf deine Auswahl. Erst wenn du **PROFIL SPEICHERN** drückst, wird die Auswahl als bestätigte Profiländerung gespeichert.

## Warum kann ich keine beliebige Bilddatei hochladen?

BUNKERFREQUENZ speichert bewusst keine großen Bilddateien oder Base64-Bilder im Spielstand. Stattdessen wird nur ein kleines "Bau-Rezept" gespeichert. Dadurch bleibt der Spielstand kompakt, Recovery bleibt einfach und eine spätere Synchronisation muss nur wenige sichere Werte an andere Spieler übertragen.

## Verändert das meine Spielwerte?

Nein. Logo/Fahne ändert weder Character-ID noch Skills, Geld, Ruf, Energie, Stress oder andere Gameplaywerte. Es ist deine bestätigte Crew-Identität für Darstellung und spätere Synchronisation.

## Was passiert mit alten Spielständen?

Alte Saves ohne Crew-Identität bleiben lesbar. Beim Laden erhalten sie eine feste neutrale Standard-Fahne. Dafür wird das alte Journal nicht nachträglich umgeschrieben.
