# 0.8.8-UX-TOOL-HELP-CLARITY

- ersetzt technische Entwicklerformulierungen im A4-Control-Deck durch kurze, handlungsorientierte Hilfetexte für Spieler
- erklärt direkt im jeweiligen Bereich: Was sehe ich? Was kann ich tun? Was verändert das Spiel tatsächlich?
- ergänzt eine kompakte Hilfe-Legende für „bestätigt“, „nur Anzeige“ und „sofort gespeichert“
- behält technische IDs nur dort sichtbar, wo sie Diagnosewert haben, erklärt sie aber laienverständlich
- verändert keine Runtime-, Gameplay-, Balance-, Save-, Journal-, Projection- oder Command-Logik
- ergänzt eine Presentation-Regression gegen Rückfall auf zentrale Fachbegriffe in den sichtbaren Hilfetexten
- spätere Idee: kontextbezogene aufklappbare Hilfe pro Panel erst nach Browser-Nutzertest prüfen; keine zusätzliche UI-Komplexität auf Verdacht
