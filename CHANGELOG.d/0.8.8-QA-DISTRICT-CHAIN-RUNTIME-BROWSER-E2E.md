# 0.8.8-QA-DISTRICT-CHAIN-RUNTIME-BROWSER-E2E

- Beide produktiven District-Micro-Stories werden in einem frischen Acceptance-Spielstand über die echte Runtime erzeugt.
- Der Test beweist Parent → Journal/Persistenz → Follow-up → read-only Timeline-Projection → `/api/state` → echtes Chromium-DOM.
- Story 001 muss sichtbar als „Folge von: Das Netz flackert“ erklärt werden.
- Story 002 muss sichtbar als „Folge von: Eine Tür steht plötzlich offen“ erklärt werden.
- Retry bleibt Exactly-once; ein späterer Zyklus in einem anderen Bezirk darf keinen offenen Follow-up verbrauchen.
- Keine Gameplay-, Balance-, Journal-, Projection- oder Browser-Produktlogik geändert.
