# 0.8.8 QA – Status-Sync-Reparaturvorlage

- `tools/status_sync.py suggest` gibt den letzten fachlich relevanten Safe-Merge-Anker und die dazu passenden Zielwerte für alle drei kanonischen Statusdateien als JSON aus.
- Der neue Modus bleibt strikt read-only: keine Datei wird geschrieben, keine zweite Statusquelle entsteht und `main` wird nicht verändert.
- `tests/quality/test_status_sync.py` regressionssichert PR-Nummer, Merge-SHA, beide Markdown-Anker und die vier relevanten `PROJEKTSTATUS.json`-Zielwerte.
- Die Laienhilfe erklärt den sicheren Ablauf `check` → `suggest` → normaler Status-PR → `/safe-merge` und ergänzt eine spätere PR-Checklisten-Idee.
