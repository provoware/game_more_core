# 0.8.8-QA-VENUE-PROFILE-OWNED-SOURCE-GUARD

- Release-Regression schützt die Eigentumsgrenze des read-only Venue-Betriebsprofils jetzt zusätzlich auf Browserseite.
- `renderProperties` darf für die sichtbare Profilzeile ausschließlich `upgradeEntry?.effective_values` verwenden.
- Ein Rückgriff auf die interne `effective_values_by_location`-Map ist in diesem Renderer ausdrücklich gesperrt, damit fremde Orte kein eigenes Betriebsprofil erhalten.
- Keine Runtime-, Property-, Balance-, Save-, Journal-, CSS- oder Gameplaylogik geändert.
- Folgeidee: dieselbe Eigentumsgrenze im echten Chromium mit eigenem/fremdem Ort, großer Schrift, Hohem Kontrast und kleinem Fenster beweisen.
