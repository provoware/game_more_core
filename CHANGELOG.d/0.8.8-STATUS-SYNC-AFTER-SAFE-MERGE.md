# 0.8.8-STATUS-SYNC-AFTER-SAFE-MERGE

- `TODO.md`, `FEATURE_POOL.md` und `PROJEKTSTATUS.json` werden auf denselben letzten fachlich relevanten `/safe-merge` synchronisiert.
- Ein read-only Git-Historienchecker erkennt künftige Statusdrift automatisch.
- Reine Status-Sync-Merges werden als Dokumentationsreparatur übersprungen, damit der Checker keinen Selbstdrift erzeugt.
- Neuer `Status Sync`-Workflow prüft Regression und Drift auf Pull Requests sowie nach Pushes auf `main`.
- Kein direkter Bot-Push auf `main`, keine Gameplay-, Runtime-, Save-, Journal- oder Presentationänderung.
